## Other generated and external assets

- Placeholder covers are generated by `src/ui/placeholder.ts`, not copied project
  screenshots. Real portfolio media is managed through QDN.
- Self-hosted fonts come from the Fontsource packages recorded in
  `package-lock.json`; their licence notices are in `third-party-licences.md`.
- Application CSS and DOM components are maintained in `src/styles/` and
  `src/views/`. Bootstrap CSS is installed through npm. The app does not bundle
  the old jQuery/plugin scripts or Bootstrap JavaScript.

To verify the inventory from any checkout, run this command from the repository
root (with `rg` and `sha256sum` available):

```bash
rg --files src/assets public | sort | xargs sha256sum
```

Update this inventory when bundled assets change. Git history records earlier
versions; a downloaded build archive is not a replacement for GitHub `main`.
